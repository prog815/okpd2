# 📁 Интерактивный справочник ОКПД2

Быстрый, бесплатный и максимально удобный онлайн-справочник по Общероссийскому классификатору продукции по видам экономической деятельности (ОК 034-2014). 

🌐 **Открыть справочник:** [https://prog815.github.io/okpd2/](https://prog815.github.io/okpd2/)

## 🎯 О проекте

Этот проект создан для специалистов госзакупок, бухгалтеров, статистиков и предпринимателей, которым ежедневно приходится работать с классификаторами. Мы устранили главные недостатки существующих аналогов: медленный поиск, навязчивую рекламу, регистрационные стены и устаревшие базы данных.

Справочник предоставляет мгновенный доступ к полной и актуальной базе кодов ОКПД2 без каких-либо ограничений.

## ✨ Возможности интерфейса

Мы сделали всё, чтобы работа с классификатором занимала секунды:

- ⚡ **Мгновенный поиск:** Результаты появляются прямо во время ввода текста. Никаких перезагрузок страницы или нажатия кнопки «Найти».
- 🔍 **Умная логика поиска:**
  - *По коду:* Понимает частичный ввод и иерархию (например, запросы `01`, `01.1` или `01.11.1` сразу покажут нужную ветку).
  - *По названию:* Поддерживает поиск по нескольким словам одновременно (логическое «И»). Например, запрос `труба сталь` найдёт все варианты стальных труб, игнорируя порядок слов.
- 🎯 **Фильтр «Только коды нижнего уровня»:** Одна галочка, чтобы скрыть все промежуточные группировки и оставить только те коды, которые разрешено указывать в извещениях о закупках в ЕИС (по 44-ФЗ и 223-ФЗ).
- 📋 **Копирование в один клик:** Нажмите на любой код, и он мгновенно скопируется в буфер обмена с визуальным подтверждением.
- 💡 **Подсветка совпадений:** Искомые слова и цифры выделяются в результатах, что позволяет мгновенно оценить релевантность находки.
- 📱 **Адаптивный дизайн:** Чистый, современный интерфейс, который одинаково удобно использовать как на большом мониторе, так и на экране смартфона.
- 🚀 **Оптимизированная скорость:** Благодаря современным методам сжатия и клиентской обработке, справочник загружается и начинает работать мгновенно, даже при медленном интернете.

## 🔄 Актуальность данных

Вам не нужно беспокоиться о том, устарели ли данные. Справочник подключён к системе **автоматического ежедневного обновления**, которая синхронизирует базу с официальными источниками Росстата. 

В текущей версии:
- **21 045** записей классификатора.
- **15 385** кодов нижнего уровня (пригодных для закупок).

## 💻 Примеры использования

Просто откройте сайт и начните печатать:
- Введите `01.11` → увидите все подкатегории зерновых культур.
- Введите `сахар тростниковый` → получите точные коды нижнего уровня для этой продукции.
- Включите галочку *«Только коды нижнего уровня»* и введите `медицинские` → увидите только те коды, которые можно указать в документации закупки.
