# 📁 Интерактивный справочник ОКПД2

Быстрый, бесплатный и максимально удобный онлайн-справочник по Общероссийскому классификатору продукции по видам экономической деятельности (ОК 034-2014, ОКПД2).

🌐 **Открыть справочник:** [https://prog815.github.io/okpd2/](https://prog815.github.io/okpd2/)

## 🎯 О проекте

Этот справочник создан для специалистов по государственным закупкам, бухгалтеров, статистиков, поставщиков, предпринимателей и всех, кому ежедневно нужно работать с кодами продукции по ОКПД2.

Главная задача проекта — помочь быстро найти корректный код ОКПД2, особенно **код нижнего уровня**, который можно указывать в извещениях о закупках в ЕИС по 44-ФЗ и 223-ФЗ.

Мы сделали интерфейс простым, быстрым и удобным: без рекламы, без регистрации и без лишних действий.

## ✨ Возможности интерфейса

- ⚡ **Мгновенный поиск.**  
  Результаты появляются сразу во время ввода. Не нужно нажимать кнопку «Найти» или перезагружать страницу.

- 🔢 **Поиск по коду — только с начала кода.**  
  Справочник понимает частичный ввод и иерархию классификатора. Например, запросы `01`, `01.1`, `01.11` или `01.11.1` покажут соответствующую ветвь ОКПД2.

- 📝 **Поиск по названию.**  
  Можно вводить одно или несколько слов. Поиск работает по логике «И»: например, запрос `труба сталь` найдёт записи, в названии которых встречаются оба слова, независимо от порядка.

- 🎯 **Фильтр «Только коды нижнего уровня».**  
  Одна галочка скрывает промежуточные группировки и оставляет только те коды, которые реально используются в закупках.

- 🗂 **Удобные карточки вместо таблицы.**  
  Каждая запись отображается отдельной карточкой: код, уровень, признак нижнего уровня и наименование продукции. Так результаты читаются легче, особенно на телефоне.

- 📋 **Копирование кода в один клик.**  
  Нажмите на код в карточке — он скопируется в буфер обмена, а появится подтверждение.

- 💡 **Подсветка совпадений.**  
  Искомые слова и цифры выделяются в результатах, чтобы сразу было видно, почему нашлась именно эта запись.

- ➕ **Порционная выдача результатов.**  
  Сначала показывается первая часть найденных записей. Ниже есть кнопка «Показать ещё», на которой видно:
  - сколько записей будет добавлено;
  - сколько уже показано;
  - сколько всего найдено.

- ⬆️️ **Навигация по странице.**  
  Сверху расположено общее меню справочников экосистемы, а внизу — плавающие кнопки для быстрого перехода наверх и вниз страницы.

- 📱 **Адаптивный дизайн.**  
  Справочник одинаково удобно использовать на компьютере, планшете и смартфоне.

- 🚀 **Быстрая работа.**  
  Поиск выполняется прямо в браузере, поэтому результаты появляются мгновенно даже при слабом интернете.

## 🔄 Актуальность данных

Справочник поддерживает **автоматическое ежедневное обновление** и синхронизируется с официальными данными Росстата.

В текущей версии:

- **21 081** запись классификатора;
- **15 432** код нижнего уровня, пригодный для закупок.

Актуальное количество записей и дата обновления всегда отображаются внизу страницы справочника.

## 💻 Примеры использования

Просто откройте сайт и начните печатать:

- Введите `01.11` → увидите все коды, начинающиеся с `01.11`, включая вложенные группировки и продукцию.
- Введите `01.11.1` → результат сузится до более конкретной ветви классификатора.
- Введите `сахар тростниковый` → найдёте подходящие наименования продукции.
- Включите галочку **«Только коды нижнего уровня»** и введите `медицинские` → останутся только те коды, которые можно указывать в документации закупки.
