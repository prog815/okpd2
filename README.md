# 📁 Интерактивный справочник ОКПД2

Мгновенный поиск по Общероссийскому классификатору продукции по видам экономической деятельности (ОК 034-2014, ОКПД2). Без без регистрации, без установки.

🌐 **Открыть справочник:** [https://prog815.github.io/okpd2/](https://prog815.github.io/okpd2/)

---

Коллеги, этот справочник — для тех, кто ежедневно работает с кодами продукции: специалистов по закупкам, бухгалтеров, поставщиков, аналитиков и предпринимателей. Главная задача — помочь быстро найти корректный код ОКПД2, особенно **код нижнего уровня**, который можно указывать в извещениях о закупках в ЕИС по 44-ФЗ и 223-ФЗ.

## 🎯 Что это и для кого

**ОКПД2** — общероссийский классификатор продукции по видам экономической деятельности. Гармонизирован с европейским КПЕС 2008. Официальный источник — Росстат.

Справочник пригодится, если вам нужно:

- подобрать код ОКПД2 для извещения о закупке по 44-ФЗ или 223-ФЗ;
- указать код продукции в статистической отчётности;
- свериться с кодом при налогообложении;
- найти код для стандартизации или учёта;
- быстро посмотреть, что входит в ту или иную группировку.

## ⚡ Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются во время ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду — строго с начала кода.** Запросы `01`, `01.11`, `01.11.1` показывают соответствующую ветвь классификатора. Точки в запросе можно не ставить.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `труба сталь` найдёт записи, где встречаются оба слова, независимо от порядка.
- **Фильтр «Только коды нижнего уровня».** Одна галочка оставляет только коды, пригодные для закупок. Удобно, когда нужен конкретный вид продукции, а не вся ветвь.
- **Карточки вместо таблицы.** Каждая запись — отдельная карточка: код, признак уровня (нижний уровень или группировка), наименование. Так удобнее читать, особенно на телефоне.
- **Копирование кода в один клик.** Клик по коду — и он в буфере обмена, а внизу экрана появляется подтверждение.
- **Копирование строки.** Кнопка `📋 строка` копирует пару «код; название» — удобно вставлять в таблицу или письмо.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. Ссылка ведёт прямо на нужный код.
- **Прямые ссылки на коды.** Каждый код можно передать коллегой через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке — видно, почему нашлась именно эта запись.
- **Навигация по странице.** Липкая панель поиска, кнопки `↑`/`↓` в правом нижнем углу.

## 🧭 Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция всех записей.
2. **Начните вводить запрос** в строке поиска — код или название.
3. **Включите галочку «Только коды нижнего уровня»**, если ищете код для закупки.
4. **Кликните по коду** в карточке — он скопируется.
5. **Нажмите `📋 строка`**, если нужно скопировать код вместе с названием.
6. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
7. **Прокручивайте вниз** и нажимайте «Показать ещё» — результаты догружаются порциями по 20.

## 📊 Примеры запросов

- `01` — вся ветвь «Продукция и услуги сельского хозяйства и охоты».
- `01.11` — зерновые, зернобобовые, семена масличных культур.
- `01.11.1` — пшеница.
- `труба сталь` — записи, где в наименовании есть оба слова.
- `медицинские` + галочка «Только коды нижнего уровня» — конкретные коды медицинских изделий.

**Популярные коды:**

- `01` — продукция и услуги сельского хозяйства и охоты;
- `10` — пищевые продукты;
- `26` — компьютеры, электронные и оптические изделия;
- `45` — услуги по оптовой и розничной торговле автотранспортными средствами;
- `85` — услуги в области образования.

## 🔗 Прямые ссылки на коды

Каждый код можно открыть напрямую — например:

- `https://prog815.github.io/okpd2/?code=01.11.1` — откроет карточку «Пшеница».
- `https://prog815.github.io/okpd2/?code=26.20` — компьютеры.

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Удобно отправлять коллеге в письме или чате — он попадёт сразу на нужную запись.

## ❓ FAQ

**Чем ОКПД2 отличается от ОКВЭД2?**

ОКПД2 — про **продукцию** (что производится или закупается), ОКВЭД2 — про **вид деятельности** (чем занимается компания). Первые 4 знака часто совпадают, но это разные классификаторы.

**Чем ОКПД2 отличается от справочника ПП 1875?**

Справочник ПП 1875 — производный от ОКПД2 с фильтрацией по национальному режиму. Если вы работаете с закупками без ограничений по нацрежиму — используйте этот справочник. Если нужны коды с ограничениями — [ПП 1875](https://prog815.github.io/okpd2-pp1875/).

**Что такое «нижний уровень»?**

Код, у которого нет потомков — конкретный вид продукции. Обычно это 5 и более цифр. Именно такие коды, как правило, указываются в извещениях о закупках. Фильтр «Только коды нижнего уровня» скрывает все промежуточные группировки.

**Почему нельзя фильтровать по разделам (A–U)?**

Разделы есть в источнике, но не входят в веб-выгрузку — так устроен формат данных. Иерархию можно смотреть через поиск по коду: запрос `01` покажет всё, что входит в раздел A.

**Почему в карточках нет примечаний «Эта группировка включает…»?**

Примечания есть в источнике, но не входят в веб-выгрузку — иначе файл данных вырос бы почти вдвое. Для сверки используйте первоисточники.

**Почему при поиске по коду `01.11` находятся и группировки, и конкретные виды продукции?**

Поиск по коду — префиксный, с начала кода. Запрос `01.11` показывает всю ветвь, включая вложенные группировки. Если нужны только конкретные коды — включите «Только коды нижнего уровня».

**Как найти код для закупки по 44-ФЗ или 223-ФЗ?**

Введите ключевое слово из названия продукции, включите «Только коды нижнего уровня» — и вы увидите только конкретные коды, которые можно указывать в извещении.
